# 🎵 CyberPlayer T-800 v2.0

> **Custom Desktop Audio Player built with C# & WPF (Russian UI)**

CyberPlayer T-800 — это современный лёгкий аудиоплеер для Windows в стиле киберпанк. Построен на базе C# и WPF с акцентом на быструю работу, удобное управление звуком и тёмный интерфейс.

Проект разработан как персональное портфолио в дуэте с AI-ассистентом.

---

## ✨ Key Features / Особенности

- **Russian Language Interface:** Полностью русский интерфейс пользователя.
- **NAudio Engine Integration:** Чистое воспроизведение звука, точная регулировка громкости и тональности.
- **Modern Cyberpunk UI:** Кастомный тёмный интерфейс на WPF, написанный с нуля.
- **Lightweight & Fast:** Минимальное потребление ОЗУ и быстрая загрузка.
- **Obfuscated & Tamper-Resistant:** Защищённый код с проверкой целостности.
- **Clean VirusTotal Rating:** 100% чистый результат сканирования (0/64).
